# Plankton Image Gallery

This repository contains plankton icons drawn by Dr. Stephanie I. Anderson. You are welcome to use them for presentations, educational materials, or fun. 

## How to Use

- Phytoplankton icons are generally listed by their scientific name.

- To download all the images, click on the **Code** button in the upper right corner of the repo page and select the **Download ZIP** option.
